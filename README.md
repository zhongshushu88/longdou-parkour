# 龙豆跑酷

一款以龙龙、豆豆、小泽、小嘉为主角，以海口为背景的六关网页跑酷游戏。

丰富版加入了随机事件、分岔路线、角色专属捷径、四种自动道具、15 秒关内小挑战、每日家庭挑战、三阶段 Boss 和无尽挑战。相同一局重试会保留路线，退出后再进入会产生新的组合。

## 开始游戏

直接打开 `index.html`，或在当前目录启动任意静态网页服务器。

## 操作

- `空格` / 点击画面：跳跃，再按一次二段跳
- `F`：投掷水果；反向追逐时会自动改为向前投
- `Shift`：加速条满后发动“椰风冲刺”
- `G`：能量满后发动“龙凤呈祥”或“兄弟同心”
- `Esc`：暂停或继续

手机和平板的主页可以竖屏浏览，开始跑酷后请横屏游玩。游戏进度只保存在当前浏览器中。
